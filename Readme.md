# 📚 Student Reading List App

A simple and interactive web application to manage your personal reading list.

## ✨ Features

* Add books with title and author name.
* Mark books as completed.
* Delete books from the list.
* Track total, completed, and pending books.
* Automatically save books using Local Storage.
* Responsive design for different screen sizes.

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Browser Local Storage

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Add books and manage your reading list.

## 👩‍💻 Project Purpose

This project was created to practise front-end web development and JavaScript functionality.
